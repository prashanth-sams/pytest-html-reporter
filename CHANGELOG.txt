Change Log
0.3.2 (30/08/2026)
-------------------
- Added an Environment overlay to the dashboard: host, platform, python and pytest versions, active plugins, invocation arguments, rootdir and generation time
- Added --environment / the environment ini key to name the environment under test; it shows as a badge beside the report title
- Added --build-info KEY=VALUE / the build_info ini key for arbitrary run details (branch, commit, CI job) in the Environment panel

0.3.1 (30/08/2026)
-------------------
- Redesigned the dashboard, suite highlights and test metrics tables with a cleaner, consistent layout
- Reworked the Archives view; fixed the archive build count (was silently dropped by a typo) and chart sizing
- Improved the PDF download: the export now always renders the desktop dashboard at a fixed viewport, waits for charts to settle, and keeps a white background
- Added an empty-state UI for the Screenshots tab when a run captures no screenshots
- Charts now re-fit on window resize instead of reloading the page, so the open tab, scroll position and table filters are preserved
- Fixed responsive alignment issues across the dashboard, side navigation and tables

0.3.0 (29/08/2026)
-------------------
- Fixed compatibility with pytest 9.x (AttributeError: '_sessionstarttime' not found)
- Fixed KeyError: 'status' in append_suite_metrics_row method
- Fixed KeyError: 'status' when accessing test results in append_suite_metrics_row
- Fixed template lookup so HTML templates are bundled and resolved from the installed package (no longer depends on a folder named "pytest-html-reporter")
- Ship HTML templates as package data (html_page/html)
- Improved safety checks for test data access
- Fixed responsive design issues
- Fixed URL reset on page load
- Fixed unit test errors
